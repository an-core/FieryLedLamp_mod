# Модифицированная прошивка FieryLedLamp
![Изображение](https://raw.githubusercontent.com/an-core/FieryLedLamp_mod/main/image.jpg)
1. Поддерживаемое оборудование: ESP32 WROOM, ESP32-S3
2. Визуальные эффекты: 131 шт.
3. Wi-Fi функционал:
- мульти-WiFi - запоминание нескольких сетей с автоматическим переключением между ними
- автоматическое переподключение к точке доступа при потери сигнала WiFi и повторное соединение с Wi-Fi, когда сеть появилась
4. Интеграция с погодными сервисами: получение данных от Яндекс.Погоды и OpenWeather
5. Отображение информации:
- вывод времени и погоды на веб-страницу устройства
- дублирование данных бегущей строкой на матрице (функция отключается)
6. Аудиовозможности (при использовании плеера):
- индивидуальные звуковые мелодии для каждого эффекта
- голосовое озвучивание текущего времени и погоды (опции настраиваются и отключаются)
7. Гибкое расписание:
- настройка автоматического включения/выключения устройства
- активация ночного режима (ночные часы)
- переключение режима цикла и запуск заданного эффекта по расписанию
8. Работа с LED-панелями:
- динамическая настройка матрицы / панели из нескольких матриц без перепрошивки 
- поддержка до 8 матриц (WS2812B 16×16)
- настраиваемый вывод на матрицу часов, даты и погодных данных, а также бегущей строки
9. Резервное копирование: создание архива с настройками
10. Обновление прошивки:
- поддержка OTA-обновлений (по воздуху)
- автоматическое уведомление о новой версии в модальном окне «Информация о ПО» (репозиторий в GitHub)
11. Управление ИК-пультом: выбор готового пульта из списка или добавление собственного
12. Диагностика: модальное окно «Статусы устройств» отображает информацию о подключённых и отключённых компонентах системы
13. Дополнительные кликабельные подсказки на web страницах

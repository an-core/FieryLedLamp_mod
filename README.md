## Модифицированная прошивка FieryLedLamp с поддержкой эффектов JINX (.out)!
# Платформы: ESP32 / ESP32-S3!

# [fieryledlamp-web-flasher](https://an-core.github.io/fieryledlamp-web-flasher/) - прошивка esp через браузер!

1. Поддерживаемое оборудование:
<br> ☑️ ESP32 WROOM
<br> ☑️ ESP32-S3 (N16R8)
<br> ☑️ дисплей TM1637 (семисегментный индикатор)
<br> ☑️ дисплей ST7789 (TFT 1.47 172*320)
<br> ☑️ сенсорная кнопка (touch TTP223)
<br> ☑️ тактовая кнопка (физическая кнопка) 
<br> ☑️ LED чип APA102 (пины: VCC, GND, DATA, CLK)
<br> ☑️ LED чип WS2812B (пины: VCC, GND, DATA)
<br> ☑️ ИК пульт (38 кГц)
<br> ☑️ радиопульт 433 МГц
<br> ☑️ MP3 плеер (DFPlayer mini)
<br> ☑️ SD карта для внешних эффектов JINX в формате .out
2. Динамическое управление модулями (включение / выключение через web только для ESP32-S3):
<br> ☑️ дисплей TM1637
<br> ☑️ дисплей ST7789
<br> ☑️ кнопка
<br> ☑️ ИК-приёмник
<br> ☑️ RF-приёмник
<br> ☑️ MP3 плеер
<br> ☑️ SD карта для внешних эффектов JINX в формате .out
    - *поддержка физической SD карты и эмуляции в LITTLEFS*
3. Wi-Fi функционал:
<br> ☑️ мульти-WiFi: запоминание нескольких сетей с автоматическим переключением между ними
<br> ☑️ автоматическое переподключение к точке доступа при потери сигнала WiFi и повторное соединение с Wi-Fi, когда сеть появилась
4. Работа с LED:
<br> ☑️ динамическая настройка матрицы/панели из нескольких матриц в web без перепрошивки
<br> ☑️ поддержка до 8 заводских матриц WS2812B 16×16
<br> ☑️ настраиваемый вывод на матрицу часов, даты и погодных данных, а также бегущей строки
<br> ☑️ количество визуальных встроенных эффектов: **130+**
<br> ☑️ поддержка анимационных эффектов, созданных программой Jinx Frame Viewer
5. Интеграция с погодными сервисами:
<br> ☑️ получение данных от Яндекс.Погоды
<br> ☑️ получение данных от OpenWeather
6. Отображение информации:
- ☑️ вывод времени и погоды на веб-страницу устройства
- ☑️ вывод даты, времени и погоды на дисплей (TM1637, ST7789), если используется
- ☑️ дублирование данных бегущей строкой на матрице (функция отключается)
7. Аудиовозможности (при использовании плеера):
<br> ☑️ индивидуальные звуковые мелодии для каждого эффекта
<br> ☑️ голосовое озвучивание текущего времени и погоды (опции настраиваются и отключаются)
<br> ☑️ во время озвучивания погоды и/или времени активный эффект не останавливается
8. Управление ИК-пультом:
<br> ☑️ выбор готового пульта из списка или добавление собственного
9. Управление физической или сенсорной кнопкой:
<br> ☑️ кол-во нажатий для действия настраивается в web
10. Выбор шрифта прямо в вэб-интерфейсе для часов, даты, погоды, бегущей строки:
<br> ☑️ 3x5 (кроме текста бегущей строки)
<br> ☑️ 5x8
<br> ☑️ 8x13
<br> ☑️ 10x16
11. Гибкое расписание:
<br> ☑️ настройка автоматического включения/выключения устройства
<br> ☑️ активация ночного режима (ночные часы)
<br> ☑️ переключение режима цикла и запуск заданного эффекта по расписанию
12. Синхронное управление несколькими лампами в одной WiFi сети
13. Резервное копирование:
<br> ☑️ сохранение архива с настройками устройства
<br> ☑️ загрузка архива с сохранёнными настройками
14. Обновление прошивки:
<br> ☑️ поддержка OTA-обновлений (по воздуху)
<br> ☑️ автоматическое уведомление о новой версии прошивки (скачать можно сразу из модального окна "Информация о ПО")
    - *дополнительное модальное окно с информацией о внесённых изменениях в обновление и идеях*
15. Статусы устройств:
<br> ☑️ модальное окно отображает информацию о подключённых и отключённых компонентах системы
16. Дополнительные кликабельные подсказки на web страницах
17. Установка пароля для Редактора файлов
18. Автоскрытие пунктов меню в web, если они отключены в прошивке (например, #define USE_MP3_PLAYER 0)
#    
**ПОДКЛЮЧЕНИЕ**:
- при первом запуске поднимется точка доступа FieryLedLamp (появится в списке wifi сетей)
- подключитесь к точке доступа (пароль 12341234)
- в браузере в адресной строке впишите 192.168.4.1 (это точка доступа)
- откроется вэб-интерфейс для управления устройством
- в настройках WiFi можно указать несколько сетей (устройство будет подключаться к доступной)

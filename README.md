<h1 align="center">Модифицированная прошивка FieryLedLamp</h1>

1. Поддерживаемое оборудование:
- [x] ESP32 WROOM
- [x] ESP32-S3 (N16R8)
- [x] дисплей TM1637 (семисегментный индикатор)
- [x] дисплей ST7789 (TFT 1.47 172*320)
- [x] сенсорная кнопка (touch TTP223)
- [x] тактовая кнопка (физическая кнопка) 
- [x] LED чип APA102 (пины: VCC, GND, DATA, CLK)
- [x] LED чип WS2812B (пины: VCC, GND, DATA)
- [x] ИК пульт (38 кГц)
- [x] радиопульт 433 МГц
- [x] мп3 плеер (DFPlayer mini)
2. Динамическое управление модулями (включение / выключение через web только для ESP32-S3):
- [x] дисплей TM1637
- [x] дисплей ST7789
- [x] кнопка
- [x] ИК-приёмник
- [x] RF-приёмник
- [x] мп3 плеер
3. Wi-Fi функционал:
- [x] мульти-WiFi: запоминание нескольких сетей с автоматическим переключением между ними
- [x] автоматическое переподключение к точке доступа при потери сигнала WiFi и повторное соединение с Wi-Fi, когда сеть появилась
4. Работа с LED:
- [x] динамическая настройка матрицы/панели из нескольких матриц в web без перепрошивки
- [x] поддержка до 8 заводских матриц WS2812B 16×16
- [x] настраиваемый вывод на матрицу часов, даты и погодных данных, а также бегущей строки
- [x] количество визуальных встроенных эффектов: **130+**
5. Интеграция с погодными сервисами:
- [x] получение данных от Яндекс.Погоды
- [x] получение данных от OpenWeather
6. Отображение информации:
- [x] вывод времени и погоды на веб-страницу устройства
- [x] вывод даты, времени и погоды на дисплей (TM1637, ST7789), если используется
- [x] дублирование данных бегущей строкой на матрице (функция отключается)
7. Аудиовозможности (при использовании плеера):
- [x] индивидуальные звуковые мелодии для каждого эффекта
- [x] голосовое озвучивание текущего времени и погоды (опции настраиваются и отключаются)
8. Управление ИК-пультом:
- [x] выбор готового пульта из списка или добавление собственного
9. Управление физической или сенсорной кнопкой:
- [x] кол-во нажатий для действия настраивается в web
10. Выбор шрифта прямо в вэб-интерфейсе для часов, даты, погоды, бегущей строки:
- [x] 3x5 (кроме текста бегущей строки)
- [x] 5x8
- [x] 8x13
- [x] 10x16
11. Гибкое расписание:
- [x] настройка автоматического включения/выключения устройства
- [x] активация ночного режима (ночные часы)
- [x] переключение режима цикла и запуск заданного эффекта по расписанию
12. Синхронное управление несколькими лампами в одной WiFi сети
13. Резервное копирование:
- [x] сохранение архива с настройками устройства
- [x] загрузка архива с сохранёнными настройками
14. Обновление прошивки:
- [x] поддержка OTA-обновлений (по воздуху)
- [x] автоматическое уведомление о новой версии в модальном окне «Информация о ПО»:
  - *дополнительное модальное окно с информацией о внесённых изменениях в обновление и идеях*
15. Статусы устройств:
- [x] модальное окно отображает информацию о подключённых и отключённых компонентах системы
16. Дополнительные кликабельные подсказки на web страницах
17. Установка пароля для Редактора файлов
18. Автоскрытие пунктов меню в web, если они отключены в прошивке (например, #define USE_MP3_PLAYER 0)
#    
**ПОДКЛЮЧЕНИЕ**:
- при первом запуске поднимется точка доступа FieryLedLamp (появится в списке wifi сетей)
- подключитесь к точке доступа (пароль 12341234)
- в браузере в адресной строке впишите 192.168.4.1 (это точка доступа)
- откроется вэб-интерфейс для управления устройством
- в настройках WiFi можно указать несколько сетей (устройство будет подключаться к доступной)

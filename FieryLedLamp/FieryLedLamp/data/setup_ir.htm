Выбор пульта
Выберите тип пульта, который вы используете для управления лампой. После смены пульта все кнопки начнут работать с новыми кодами.
Подсказка: После смены пульта перезагрузка не требуется. Сохранение происходит автоматически.
Добавить новый пульт
Нажмите "Начать обучение", затем по очереди нажимайте кнопки на новом пульте. Для каждой кнопки нужно нажать её один раз.
Нажмите кнопку:
IR_ON_OFF
Прогресс:
0 / 21
Ожидание нажатия кнопки...
Информация
  • Поддерживается несколько типов пультов
  • Коды кнопок загружаются из файла ir_codes.json
  • Для добавления нового пульта используйте функцию "Добавить новый пульт"

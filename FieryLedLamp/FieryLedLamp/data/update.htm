Как получить .bin файл

Бинарники прошивки (firmware)
  • В Arduino IDE: Скетч -> Экспорт бинарного файла, ждите завершения.
  • Перейдите в папку C:\Users\user\AppData\Local\Temp (у вас вместо user - имя пользователя).
  • Найдите папку arduino_build_739627 (номер будет другим).
    Совет: отсортируйте по типу и поставьте галочку только на "Папка с файлами".
  • В ней будут нужные файлы:
    • FieryLedLamp.ino.bootloader.bin
    • FieryLedLamp.ino.partitions.bin
    • FieryLedLamp.ino.bin
Примечание: если папка Temp не найдена - она скрыта. Включите в параметрах папок "Показывать скрытые файлы, папки".
Бинарник файловой системы
  • В Arduino IDE: Инструменты -> ESP32 Sketch Data Upload, нажмите OK, подождите пару секунд.
  • Не обращайте внимание на ошибку - файл всё равно создаётся.
  • Перейдите в ту же папку Temp/arduino_build_xxxxx.
  • Там будет файл: FieryLedLamp.littlefs.bin
Загрузка на ESP32
  • Для загрузки бинарников в плату ESP32 используйте утилиту flash_download_tool
  • 🔗 Ссылка на утилиту flash_download_tool
Адреса для ESP32-S3
  • FieryLedLamp.ino.bootloader.bin - 0x0
  • FieryLedLamp.ino.partitions.bin - 0x8000
  • FieryLedLamp.ino.bin - 0x10000
  • FieryLedLamp.littlefs.bin - 0xc90000
